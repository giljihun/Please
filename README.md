# Please!

팬이 스마트폰만으로 셀럽/선수에게 가상 렌즈 사인 경험을 받을 수 있는 글로벌 iOS 앱.

화면에 사인하면 렌즈에 새기는 듯한 경험을 선사합니다.

## 컨셉
- 실제 팬 문화인 "카메라 렌즈 사인"을 스마트폰 화면 위에서 재현
- 네이밍 유래: 르브론 제임스가 "please"라고 말한 어린 팬을 위해 멈춰준 일화
- 타깃: K-pop 팬, 스포츠 팬, 콘서트 관객, 콘텐츠 크리에이터

## 기술 스택
- Swift / SwiftUI (앱 쉘) + UIKit (캡처 세션 코어)
- AVFoundation — 카메라, 녹화, 프레임 합성
- Vision — 손 추적 (제스처 모드)
- SwiftData — 라이브러리 메타데이터
